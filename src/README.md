# SimPlayer Purchase Python Package

구조화된 simulation 요청과 결과, 결정론적 상태 전이, 선택형 model-backed actor/critic, Memory·Neptune adapter와 평가 도구를 제공하는 Python package다.

SimPlayer Purchase는 호출자가 지정한 상품에 대한 사용자 반응을 시뮬레이션하는 기술 프로토타입이며, recommender나 production-calibrated CVR 모델이 아니다. 출력 결과도 실제 구매 정확도를 보장하지 않는다.

설치, 평가 한계, 데이터 취급과 AgentCore 배포 절차는 저장소 루트의 [README](../README.md)와 [문서 안내](../docs/README.md)에서 확인한다.
